# AffectUI for Formal Mind

AffectUI's components, blocks, screens, motion and illustrations, used by Formal Mind's chat, with Formal Mind's
wrappers in `formalmind/`. Formal Mind (formalmind/formalmind) mounts this repository as the submodule `packages/ui`
and imports it as `@formalmind/ui`; builds without it fall back to the app's own chat components.

**Licence.** The AffectUI files (everything outside `formalmind/`) are AffectUI's, used under Formal Mind's AffectUI
licence, which allows them in a public repository. This repository is public, but those files are not open source:
reuse outside Formal Mind needs your own AffectUI licence. Formal Mind's wrappers in `formalmind/` are MIT.

Never commit an AffectUI token here.
