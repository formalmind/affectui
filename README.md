# AffectUI (private)

Licensed AffectUI source (components, blocks, screens, motion, illustrations), used by Formal Mind's chat.
Private: formalmind/formalmind is public and mounts this repository as the submodule `packages/ui` and imports it as `@formalmind/ui`.
Formal Mind's own wrappers live in `formalmind/`; builds without this repository fall back to the app's own
chat components.

Never commit an AffectUI token here.
